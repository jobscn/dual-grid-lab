操作说明

「分层模板」使用2套必需16态图集：泥土地形＋透明草皮，另有1套可选独立背景墙。三张常驻卡片按上→下排列，点卡片切换编辑层，直接开关各层显示。每层＋或拖图会在已有作品后追加同层变体；首次加图替换教学底稿。「替换本层」替换该层全部变体，其他层保留。缩略图可直接选择，移除只影响所选变体，最后一张保留。单层作品与分层工作分别保留；单格尺寸在图层堆栈的设置图标中调整，完整绘制包在「文件→导出全部图层」。工具内置为原创教学底稿，不含泰拉瑞亚原图。

图层堆栈中每层的「层预览」可固定单层预览，再点或点击右侧固定预览标签的×恢复合成。固定层与编辑层独立，切换编辑层不会改变固定对象；固定期间临时显示该层，不改各层显隐。右侧工作区标题栏会显示已固定层名称。自由试画仍修改当前编辑层。

草皮图集按地形16态选形；自由试画选草皮层时仅画独立覆盖区，不修改泥土。覆盖区用四角几何硬裁切收口，不模拟草生长、光照、斜坡或原版墙外扩；这些预览信息不会自动变成AnyRuleD／Unity规则。选择墙层则编辑独立墙占用。每层撤销分开，清空仅影响当前层。

导入 PNG / WebP / JPEG，每张最大16 MiB，可多选同地形的变体（最多8套，同尺寸／排版；本批文件≤32 MiB，整组解码≤16777216像素）。单层在素材预览标题栏点击「导入图集」，分层使用每层＋。标题栏的设置图标打开切分／映射，也可追加变体或载入原创示例；不同材质／背景墙不要作为随机变体。

多变体时，单层模式在顶栏选择左侧当前变体，分层模式直接点所在层的缩略图；右侧可固定此套或按位置稳定混用。「换纹理」只换纹理种子，不改地形；缩放、重绘和场景PNG导出使用相同选择。图集／映射导出仅针对左侧当前变体，跨变体共边仍需检查。每张缩略图是一套完整16态图集，不是单块tile。

画布100%／1×是各自适应当前窗口的基准，不是原像素大小；切分辨率后保持相对倍率和位置，不会把4／8px缩成小图。倍率按钮回到1×，回正同时居中。顶部「原像素1:1」才是一个源像素对应一个CSS像素，按钮显示1:1；导出始终保持原生尺寸。

像素模式在原生网格生成硬边底稿，固定颜色、alpha仅0或255，支持4／8／16～256px。导出辅助层按像素绘制，页面网格保持1px细线；4／8px省略放不下的编号，细边与厚度按整像素量化。双线性保留平滑路径。导入作品不做去透明或改色；精查真实像素可选「原像素1:1」。

顶栏图标一键切换切分线／逻辑线／角点／编号／海面，悬停查看名称；快捷键依次为 G／L／P／N／W，B 切换背景。输入框和弹窗内不触发。

素材预览标题栏的「导出」集中提供当前变体图集PNG、映射JSON及绘制底稿。底稿可选分层SVG、纯底色PNG、含当前辅助线的参考PNG或透明辅助线PNG。蓝色海面不导出；在新图层作画，导回前隐藏参考／辅助线层。

左侧「画法」选择平面或伪透视：上沿薄边、下沿厚立面，厚度在底稿设置中调节。伪透视自动使用正视角；切等距会恢复平面。只影响生成底稿；导入作品不会被重绘。立面收在格内，不模拟真实高度或悬挑。

未导入时左侧显示底稿；导入成功后自动显示作品，标题旁「对照底稿／返回作品」只切换左侧，不替换作品或右侧拼接。对照与底稿导出跟随作品原生单格尺寸；切分无效时明确暂停作品预览，可点击对照继续看底稿。

等距仅支持 2:1 地面，不支持高度或越界悬挑。输入类型与预览视角独立。

顶栏「选取：渲染格／逻辑格」决定单击对象，辅助线开关不改变选取模式。悬停虚线预览，单击实线锁定，再点同位置、点画布信息的×或Esc取消。选逻辑格显示半格偏移主选区及周围4个渲染格；边界不环绕，素材外按0读取。淡色四分区只表示位置贡献，不要求素材按象限独立绘制。

各画布左上角显示精简选格信息，悬停信息可查看完整素材来源；点×或Esc取消选区。右上角链条按钮开启跨画布关联：点击渲染格，在当前画布、底稿和其他可见画布标出同一图层的相同状态，不区分纹理变体；点击逻辑格，底稿标出周围四格的状态切片，场景匹配中心值及左上／右上／左下／右下四格的完整组合。覆盖层还匹配实际覆盖区；素材范围外不发起关联。固定预览其他图层时不跨层关联。关闭链条保留单点选取。图集设置中的切片追踪独立，取消追踪与取消选区互不影响。

自由试画可向四周延伸，支持负坐标与分散笔画，平移后继续绘制。默认绘制，需点「选取」才只选不画；再点返回原笔刷。移动／选取／绘制互斥，选取时拖动仍平移，不记录笔画或撤销。试画支持 Ctrl / Cmd + Z，最多撤销40步。PNG包含原始区域与可见图层的扩展笔画；超出16777216像素或单边32767px时会提示，请改用完整备份保留全部作品。顶栏用小圆点与文字显示自动保存结果；「文件」提供立即保存和完整备份导出／载入。清理浏览器数据、更换浏览器或入口路径前请导出备份。所有图像只在本地处理，选区叠层不进入PNG／SVG／绘制包。

检查栏点击「下一张」翻页，圆点可直接跳转。钉住会新增一栏并保留当前组，浏览栏自动下一张；最多4个钉住栏，每栏仍可独立翻页。「换一组」随机生成新种子；手动输入种子后按Enter可重现该组。换一组不影响钉住栏；素材与显示设置同步更新，窄屏可横向滚动分栏。

左侧底稿常驻，可收为窄栏。右侧拼接检查与自由试画互斥，可整体隐藏；点击窄栏恢复。收起不清空钉住、种子或笔画，至少保留一侧展开。窄屏两侧展开时上下排列。

各画布视图独立；顶部缩放用于统一重置全部画布。试画默认左键绘制，点「移动」后左键平移，也可按住空格或使用中键临时平移。拖动不触发选格，翻检查图会自动回正。

分层案例：选择包含分层素材的页面备份 JSON，一次恢复图层与场景，保持分层模式。载入前会自动下载当前工作备份；普通备份仍可从「文件」载入。

泰拉瑞亚素材怎么导入？
  1. 先把原始素材整理成完整16态图集。原版大图的帧排布不能直接当作4×4使用，也不能用游戏截图代替图集。
  2. 切到「分层模板」，在目标层点＋或拖入PNG：泥土放地形层，透明草皮放草皮层，背景墙放墙层。同层可多选纹理变体。
  3. 点「切分与映射」核对排版。默认每格16 px；其他尺寸先在图层设置中调整。64×64图集选4×4、边距0、间距0，状态排版须与素材一致。
  4. 在右侧检查拼接，或切到「自由试画」。用图层的预览按钮单独检查各层。

原创案例可离线打开；Open-Terraria案例首次需联网载入参考素材，也可从本地导入自己的图集。这里的16态拼接与原版自动选帧规则有差异。
