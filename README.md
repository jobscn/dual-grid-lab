# Dual Grid Lab

一个给美术使用的 16-tile 绘制与拼接检查工具，可辅助 AnyRuleD 的素材制作。纯静态网页，无需安装 Unity。

**[在线使用](https://jobscn.github.io/dual-grid-lab/)**

## 能做什么

- 导入 PNG、WebP 或 JPEG 图集，自动识别尺寸并切分；排版、边距和间距可调整。
- 用不同拼接场景检查外角、内角、孔洞、窄路和对角连接，最多钉住 4 张对照图，也可以自由试画。
- 导出连续绘制底稿、插件图集和映射 JSON；支持正视、等距和伪透视底稿，提供点过滤与双线性过滤。

## 怎么用

1. 没有素材时，直接在左侧导出底稿，放进绘图软件作画。
2. 把画好的图集拖入页面，在「切分 / 映射」中确认尺寸与排列。透明空白格也要保留。
3. 在右侧切换检查图或自由试画，查看接缝；需要时钉住多张对照。

两侧画布都可滚轮缩放、拖动平移，右下角可以回正。默认使用像素风硬边显示。

## 离线使用与开发

下载仓库 ZIP 并解压，直接打开 `offline.html`，不需要联网或启动服务器。

开发时修改 `index.html`、`styles.css` 和对应 JS 文件，然后用 Node.js 执行：

```sh
node build.cjs
```

这会更新离线页面和 `templates/` 下的示例底稿，无需安装 npm 依赖。推送到 `main` 后，GitHub Pages 会自动更新在线版。

## 隐私与许可

导入的图片只在当前浏览器内处理，不会被工具上传。试画内容不会自动保存，关闭页面前请导出需要保留的图片。
